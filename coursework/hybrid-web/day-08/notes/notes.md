# package managers

## npm

- npm is the default package manager

```bash

# create package.json file
> npm init

# install dependency
# > npm install <dependency name>
> npm install express

# uninstall dependency
# > npn uninstall <dependency name>
> npm uninstall express

```

## yarn

```bash

# install yarn
> npm install -g yarn

# create package.json file
> yarn init

# install dependency
# > yarn add <dependency name>
> yarn add express

# uninstall dependency
# > yarn remove <dependency name>
> yarn remove express

```

# utilities

## nodemon

- used to restart the application automatically when the source code gets updated

```bash

# install nodemon
> npm install -g nodemon

# start the node application using nodemon
# > nodemon <server file name>
> nodemon server.js

```
