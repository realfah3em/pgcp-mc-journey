# PGCP-MC Journey

Documenting my coursework in **PGCP-MC (Post Graduate Certificate Programme in Mobile Computing)** at Sunbeam Institute (a C-DAC ACTS training centre) — following the official curriculum from programming foundations through to mobile app development.

## About

This repo is my public learning log: code exercises, notes, and small projects as I work through the course. The goal is to track progress consistently and end up with a portfolio that shows the path, not just the destination.

> PGCP-MC is C-DAC's certificate programme in mobile computing (1200 hours / 24 weeks / 40 credits), delivered through Sunbeam as an authorized C-DAC ACTS centre.

## Structure

Folders follow the course's actual module sequence:

```
pgcp-mc-journey/
├── 01-c-programming/         # Programming foundations
├── 02-os-linux/               # OS Concepts & Linux Programming
├── 03-dbms/                   # Introduction to DBMS
├── 04-data-structures/        # Algorithms & Data Structures
├── 05-java-oop/                # Object-Oriented Programming with Java
├── 06-web-java/                # Web-Based Java Programming
├── 07-android/                 # Mobile (Android) Programming
├── 08-hybrid-apps/             # Hybrid Mobile Apps Programming
├── 09-ai-on-mobile/            # AI on Mobile Platforms
├── 10-project/                  # Final course project
└── PROGRESS.md                 # Day-by-day log
```

Each module folder gets its own short README with exercises and notes as that section fills in — folders for topics not yet reached stay empty (or absent) until I get there.
